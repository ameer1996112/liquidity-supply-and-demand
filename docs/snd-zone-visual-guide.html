Implementation Contract

Rule TradingView visual meaning Pine behavior we want
Source candle Demand starts from the last bearish candle before bullish displacement. Supply starts from the last bullish candle before bearish displacement. Detect the source candle first, then only inspect the first displacement candle next to it for wick extension.
Normal zone boundary Demand top is the bearish source high; bottom is whichever is lower: bearish source low or first bullish displacement low. Supply bottom is the bullish source low; top is whichever is higher: bullish source high or first bearish displacement high. No broad future wick scan. Use only the source candle and the first opposite displacement candle.
Accuracy zone Accuracy zones are a refinement layer. If the source candle violates the accuracy rule from the first transcript, draw the source body only. D-ACC and S-ACC must be labeled separately from normal zones so debugging stays clear.
Waiting BOS Yellow zone exists, but it is not tradable yet. Keep as candidate until price breaks the required structure level.
Early return If price comes back into the zone before BOS, the setup is dead. Invalidate or hide the candidate. Same-color leaving candles do not count as a tap.
Liquidity At least two opposite-color candles form the pool, then price must take its own high/low. Reject one-candle liquidity unless explicitly enabled as a lower-confidence debug mode.
