# Project Roadmap

## Phase 1: Tooling & Setup (Active)
**Goal:** Build a robust local utility (Node.js/Python script) that leverages the Jira REST API and GitHub CLI to manage project boards, Epics, Sprints, Tasks, and Bugs.
**Status:** Not Started

## Phase 2: Autonomous Workflow Implementation
**Goal:** Strictly enforce the Autonomous Workflow Standard Operating Procedure. Automate the translation of features into Jira tickets, automated Git branching, code execution, and Jira Smart Commits back into Pull Requests.
**Status:** Not Started

## Phase 3: Trading Strategy Execution Refining
**Goal:** Ensure the trading logic fully aligns with the 5-minute timeframe and incorporates Liquidity, Supply, and Demand concepts (Flip & Directional Close mechanics).
**Status:** Not Started
