# Project Requirements

## Core Objective
Successfully transform the existing Algorithmic Trading System to run autonomously, utilizing an AI project manager that strictly implements features via Jira, GitHub branching, coding, and smart committing.

## Table Stakes (Must Have)
- **Phase 1: Autonomous Jira Utility**: A local utility (`scripts/autonomous-jira-cli.js`) capable of interacting with the Jira REST API to generate issues and sprints.
- **Strict Jira Workflow Integration**: Every new feature/idea must:
  1. Check for/create an active sprint.
  2. Generate a Jira Ticket (with title, description, time estimate, assignee).
  3. Create and checkout a Git branch named `feature/[ISSUE-KEY]-desc`.
  4. Perform the code execution (adhering to 5-min/Supply-Demand strategies).
  5. Commit using Smart Commits (`[ISSUE-KEY] feat: ... #time #transition`).
  6. Create a Pull Request against the repository.

## Differentiators (Should Have)
- Maintain alignment strictly with existing liquidity, supply, and demand concepts (Flip/Directional Close).
- Clean tracking of Epics and Tasks inside Jira.

## Exclusions (Out of Scope)
- Manual bypassing of the Jira workflow (unless explicitly required for debugging the system itself).
