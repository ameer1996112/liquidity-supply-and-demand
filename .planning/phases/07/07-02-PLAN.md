# Phase 7 Plan 2: Execute simultaneous trade broadcasting

## Requirements
- EXEC-02: Trading signals are routed almost simultaneously across all configured MetaAPI accounts.

## Steps
1. Refactor `MetaApiAdapter` to accept specific explicitly passed `token` and `account_id` rather than drawing globally from settings.
2. In `worker.py`, instantiate a mapped dictionary of `MetaApiAdapter` instances against each configured account.
3. Map trade generation functions inside the webhook `while True` loop to build tasks and fire via `asyncio.gather(*tasks)` for parallel latency execution.
