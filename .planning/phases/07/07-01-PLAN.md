# Phase 7 Plan 1: Configure Multi-Account parsing

## Requirements
- EXEC-01: Python worker.py dynamically parses a list of MetaAPI account tokens from configuration.

## Steps
1. Update `config/settings.py` to ingest a new `META_API_ACCOUNTS` string literal.
2. Add a parser that splits the string by comma, and then splits each node by `|` generating a mapping of `{ account_id: token }`.
3. Provide fallback to the legacy `META_API_TOKEN` and `META_API_ACCOUNT_ID` if the multi-account string isn't defined.
