# Phase 5 Plan: Two-Way GitHub / Jira Sync

## Goal
Upgrade the `autonomous-jira-cli.js` script to actively push GitHub PR links as comments on Jira issues and forcefully transition Jira ticket statuses via the Atlassian REST API, rather than relying on unreliable Git Smart Commits.

## Proposed Changes
### `scripts/autonomous-jira-cli.js`
- [MODIFY] Add a new `addComment(issueKey, text)` utility using the Atlassian `POST /rest/api/3/issue/{issueIdOrKey}/comment` endpoint.
- [MODIFY] Add a new `getTransitions(issueKey)` utility using `GET /rest/api/3/issue/{issueKey}/transitions` to dynamically find the correct Transition ID for "Done" or "In Review" (since IDs change per Atlassian project).
- [MODIFY] Create the `sync-pr` command: `node scripts/autonomous-jira-cli.js sync-pr "<issueKey>" "<prUrl>"`. It will automatically add the PR link as a comment and transition the ticket to "In Review" or "Done".
- [MODIFY] Update the existing `finish-feature` command so that it captures the `gh pr create` URL output and automatically triggers the Jira Sync logic immediately after creating the PR.

## Verification Plan
### Manual Verification
- We will execute a test run of `node scripts/autonomous-jira-cli.js sync-pr DEV-27 "https://github.com/test/pull/1"` and check that Atlassian receives the comment and the transition executes smoothly before closing the milestone.
