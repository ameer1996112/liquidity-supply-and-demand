# Phase 2: Account Card UI - Plan 01 (Hooks & Wrapper)

## Goal
Create the React hook for fetching prop firm metrics and the wrapper section within `EnhancedAccountCard`.

## Requirements
- UI-06: Create `usePropFirmChallenge` hook to fetch data from `/api/v1/prop-firm/challenge-status/...`.
- UI-07: Implement SWR or 10s interval polling.
- UI-08: Add `PropFirmSection` component structure to `EnhancedAccountCard`.

## Implementation Steps
### 1. `frontend/src/hooks/usePropFirmChallenge.ts`
- Implement a custom hook using `SWR` or `useEffect` + `setInterval` to fetch `/api/v1/prop-firm/challenge-status/{account_id}`.
- Include an API patch call parameter for updating challenge configuration.

### 2. `frontend/src/components/accounts/PropFirmSection.tsx`
- Build the shell component that will take `account_id` and use the hook.
- Render skeleton loader while fetching.

### 3. `frontend/src/components/accounts/EnhancedAccountCard.tsx`
- Import and append `PropFirmSection` within the card rendering block.

## Verification
- Run Next.js dev server and verify `EnhancedAccountCard` initiates network requests to the new endpoint on 10s intervals.
