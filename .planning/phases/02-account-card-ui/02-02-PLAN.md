# Phase 2: Account Card UI - Plan 02 (Sub-Components)

## Goal
Implement the interactive and visual components of the Prop Firm tracker.

## Requirements
- UI-01: Progress bars (daily DD, total DD, profit target).
- UI-02: Trading days counter.
- UI-03: 80% Warning banners.
- UI-04: Unknown firm fallback.
- UI-05: Inline challenge type selector.

## Implementation Steps
### 1. `frontend/src/components/prop-firm/ProgressBars.tsx`
- Accept metrics from hook.
- Render `<Progress />` components with dynamic color mapping (Green/Amber/Red based on 80% threshold).

### 2. `frontend/src/components/prop-firm/WarningBanner.tsx`
- Render conditionally if any metric exceeds 80%.
- Display text specifying which metric is at risk.

### 3. `frontend/src/components/prop-firm/ChallengeSelector.tsx`
- Inline selector for challenge phase if firm is detected but phase is not configured.
- Disappears upon selection and successful PATCH request.

### 4. `frontend/src/components/accounts/PropFirmSection.tsx`
- Combine all sub-components.
- Implement the "Unknown Firm" fallback UI.

## Verification
- Visualize components across mock data scenarios confirming layout and color changes structure.
