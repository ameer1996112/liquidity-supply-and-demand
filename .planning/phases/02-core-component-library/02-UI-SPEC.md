## Spacing Scale

Declared values (multiples of 4 only). These are the spacing increments the executor must use inside every component styled in this phase.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Button icon padding, compact cell padding |
| md | 16px | Default button horizontal padding, card inner padding |
| lg | 24px | Card header/footer padding, section gaps |
| xl | 32px | Card vertical gap (gap-6 = 24px is current, xl reserved for layout) |
| 2xl | 48px | Major section breaks (layout phases, not this phase) |
| 3xl | 64px | Page-level spacing (layout phases, not this phase) |

Exceptions:
- Button touch targets: minimum 36px height (h-9 = 36px default, h-10 = 40px large) — already set in button.tsx size variants, do not change.
- Table head row height: 40px (h-10) — keep as-is.

Source: CONTEXT.md decisions + existing button.tsx size variants.

## Typography

The type scale is defined in globals.css as CSS custom properties. Components in this phase must reference these tokens rather than Tailwind's default text-* utilities.

| Role | Token | Size | Weight | Line Height | Usage in this phase |
|------|-------|------|--------|-------------|---------------------|
| Label | --to-label / --text-xs | 11px | 600 (semibold) | 1.2 | Badge text, table head labels, button xs |
| Body | --to-body / --text-sm | 13px | 400 (normal) | 1.5 | Table cells, card descriptions, default button text |
| Heading | --to-heading / --text-lg | 17px | 600 (semibold) | 1.2 | Card titles (CardTitle), panel headers |
| Display | --text-2xl | 24px | 700 (bold) | 1.1 | KPI values only — not used in base components this phase |

Font weights in use (exactly 2):

- Semibold: var(--to-weight-semibold) = 600

Button and badge text use weight 600 (Semibold). No medium (500) weight is used in this phase.

Source: globals.css lines 178-198 (text scale + weight tokens).

## Color

60/30/10 split applied to the dark terminal aesthetic.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | --to-bg | #080b10 | Page background (body, layout shells) |
| Secondary (30%) | --to-surface / --to-surface-raised | #0d1117 / #161b22 | Cards (glass-panel), table rows, input backgrounds |
| Accent (10%) | --to-accent-amber | #f0b90b | Reserved — see list below |
| Destructive | --to-error / --to-accent-red | #f6465d | Destructive button variant, destructive badge variant |

Accent (--to-accent-amber / --glow-amber) is reserved exclusively for:
1. Primary button hover box-shadow: var(--glow-amber)
2. Form input focus ring: box-shadow var(--glow-amber) at 50% opacity
3. Primary button background (via existing --color-amber bridge token)

Accent is NOT used for: ghost buttons, secondary buttons, card borders, table hover, badge borders, or any passive state.

Additional semantic tokens used in this phase:

| Token | Hex | Assigned to |
|-------|-----|-------------|
| --to-success / --to-accent-green | #0ecb81 | success badge variant |
| --to-error / --to-accent-red | #f6465d | destructive badge + destructive button |
| --to-border | #21262d | All component borders (card, table dividers, input) |
| --to-border-subtle | #161b22 | Table row dividers (lighter visual weight) |
| --to-text-primary | #e6eaf0 | Default text in buttons, card titles, table cells |
| --to-text-secondary | #8b95a5 | Card descriptions, table captions, placeholder text |
| --to-text-dim | #4d5666 | Disabled state text, metadata |
| --to-surface-raised | #161b22 | Ghost button hover bg, table row hover bg, skeleton base |
| --to-surface-overlay | #1c2230 | Skeleton shimmer midpoint (secondary) |

Source: globals.css :root, CONTEXT.md decisions.

## Component Contracts

### Button (button.tsx)

Base classes (keep): `inline-flex items-center justify-center gap-2 whitespace-nowrap rounded-md text-sm font-semibold transition-all disabled:pointer-events-none disabled:opacity-50`

Border radius: `rounded-md` = 6px. Do NOT change to 12px (that is card/panel radius only).

| Variant | Background | Text | Border | Hover | Focus ring |
|---------|-----------|------|--------|-------|------------|
| default (primary) | bg-[var(--to-accent-amber)] | text-[#080b10] (dark on gold) | none | box-shadow: var(--glow-amber) | var(--glow-amber) at 50% |
| secondary | bg-[var(--to-surface-raised)] | text-[var(--to-text-primary)] | 1px solid var(--to-border) | bg-[var(--to-surface-overlay)] | var(--glow-amber) at 50% |
| ghost | transparent | text-[var(--to-text-secondary)] | none | bg-[var(--to-surface-raised)] | var(--glow-amber) at 50% |
| outline | transparent | text-[var(--to-text-primary)] | 1px solid var(--to-border) | bg-[var(--to-surface-raised)] | var(--glow-amber) at 50% |
| destructive | bg-[var(--to-error)] | text-white | none | bg-[var(--to-error)] at 90% opacity | var(--glow-red) at 50% |
| link | transparent | text-[var(--to-accent-amber)] | none | underline | none |

Size variants: keep all existing size classes unchanged (h-9, h-8, h-10, size-9, etc.).

Transition: `transition-all` covers both color and box-shadow — no additional transition needed.

| CardFooter | (unchanged) | (unchanged) |
| CardHeader | (unchanged — layout only) | (unchanged) |
| CardContent | (unchanged — layout only) | (unchanged) |

### Skeleton (skeleton.tsx)

Remove: `bg-accent animate-pulse`
Add: `skeleton-shimmer rounded-md`

The `skeleton-shimmer` class is already defined in globals.css (lines 966-974):
```
background: linear-gradient(90deg, var(--to-surface-raised) 25%, rgba(255,255,255,0.04) 50%, var(--to-surface-raised) 75%);
background-size: 800px 100%;
animation: skeleton-shimmer 1.6s ease-in-out infinite;
```
Direction: left-to-right (standard fintech pattern). Duration: 1.6s ease-in-out. No changes to keyframe needed — it already exists.

Skeleton shape guide for page coverage:
- Dashboard: Card skeleton (full width, h-24), metric value skeleton (h-8 w-32), chart skeleton (h-48 w-full)
- Positions: Table row skeleton (h-10 w-full, repeat 5x)
- Analytics: Chart skeleton (h-64 w-full), stat card skeleton (h-16 w-full, repeat 4x)
- Risk: Metric gauge skeleton (h-32 w-32 rounded-full), table row skeleton (h-10)
- PropFirm: Progress bar skeleton (h-4 w-full), stat card skeleton (h-20 w-full)

Shapes must match layout exactly — skeleton dimensions must equal the rendered component dimensions.

## Copywriting Contract

This phase modifies visual styling only. However, the following copy elements are embedded in component defaults and must be consistent.

| Element | Copy |
|---------|------|
| Primary CTA (button default) | Use verb-first labels: "Save Changes", "Confirm", "Apply" — never "OK" or "Submit" alone |
| Destructive button label | Use specific action: "Delete Position", "Cancel Order", "Remove Rule" — never just "Delete" |
| Destructive confirmation copy | "[Action] cannot be undone. This will permanently [consequence]." |
| Disabled button tooltip | "Unavailable — [reason if determinable]" |
| Empty state heading | "No [entity] yet" (e.g. "No positions yet") |
| Empty state body | "When [event occurs], they'll appear here." with a secondary CTA if applicable |
| Error state | "[What failed]. [What to do next]." e.g. "Failed to load positions. Refresh or check your connection." |
| Skeleton aria-label | `aria-label="Loading [section name]"` on skeleton wrapper containers |
| Badge labels | Uppercase only for status/side badges (LIVE, PAPER, LONG, SHORT). Mixed case for all other badge variants. |
| Table empty row | The base Table component accepts an `emptyText` prop from callers. No default string is hardcoded in the component. Callers must supply context-specific copy (e.g. "No positions yet", "No trades found"). |

Source: CONTEXT.md (destructive pattern), CLAUDE.md frontend standard (loading/empty/error states).
