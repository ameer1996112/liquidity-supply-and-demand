# Phase 3: Caching and Polish - Plan 01 (Worker)

## Goal
Implement a background loop in the worker to asynchronously cache prop firm metrics for every account into Redis every 20 seconds.

## Requirements
- CACHE-02: Background worker writing prop firm metrics to Redis.
- Key format: `prop_firm:metrics:{account_name}`
- TTL: 30s
- Interval: 20s

## Implementation Steps
### 1. Identify/Create Worker Loop
- Add an async task in `src/worker.py` (or a dedicated `src/workers/prop_firm_cache_worker.py`).
- Fetch all active `account_name` instances from `broker_profiles`.

### 2. Cache Logic
- Iterate over each account and call `PropFirmDetector.get_account_status(account_name)`.
- Serialize the resulting dictionary to JSON.
- Store via Redis client with a 30 second expire TTL `EX 30`.
- Sleep 20 seconds before next iteration.

## Verification
- Run the worker script and observe Redis keys using `redis-cli keys "prop_firm:metrics:*"`.
