# Phase 8 Plan 1: Discord alert on Jira Bug creation

## Requirements
- NOTIF-01: Python Worker pushes an embedded Discord message when it fires a Jira Bug via the Error-to-Ticket pipeline.

## Steps
1. In `src/adapters/jira.py`, after successful `response.status_code in (200, 201)`, call `send_bug_alert_async(title, description, data.get("key"))`.
2. The `send_bug_alert_async` function in `src/adapters/discord.py` sends a red error embed with the Jira ticket key to `DISCORD_WEBHOOK_URL` (or `DISCORD_ALERTS_WEBHOOK_URL`).
