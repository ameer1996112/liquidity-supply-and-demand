# Phase 2: Backend Stability & Bug Fixes

## Objective
Address foundational backend issues ensuring the API and worker are rock solid. This means 0 lint errors, 100% test coverage maintenance, and eliminating two critical runtime exceptions (MetaAPI timeouts, yfinance data 404s).

## Execution Steps
1. **Ruff Linting**:
   - Run `ruff check src/ config/ tests/ --fix` to auto-resolve many issues.
   - Run `ruff check` again and manually resolve any remaining type or formatting issues inside `src/`.
2. **MetaAPI Timeout Mitigation**:
   - Locate `meta_api_adapter.py` (or the equivalent module executing trades/reconciliation).
   - Trace the background reconciliation task and increase the timeout parameters from `5.0` to something appropriate (e.g., `15.0` or `30.0`), while leaving real-time executions short `2.0` or `5.0`.
3. **yfinance 404 Bug Resolution**:
   - Search the repo (`grep` or `find`) for `yfinance` and specifically the `GBPJPY` invocation blocking data retrieval. 
   - Apply robust exception handling or remap the ticker if yfinance changed the ticker name (e.g. `GBPJPY=X`).
4. **Validation via Test Suite**:
   - Execute `PYTHONPATH=/workspace pytest tests/ -v`. Ensure all 11 backend tests still pass perfectly. 

## Must-Haves
- `[ ]` `ruff check src/ config/ tests/` returns zero errors
- `[ ]` 11 pytest backend tests pass
- `[ ]` MetaAPI operations complete without 5s timeout exceptions (timeout hardcoded limit raised)
- `[ ]` yfinance logic gracefully recovers or correctly maps currency pairs.
