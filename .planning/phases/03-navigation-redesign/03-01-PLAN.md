## Tasks

### Task 1: Update Active Link Border to Left-Only Accent Bar

<read_first>
- `frontend/src/components/layout/Sidebar.tsx` — full file, understand exact current active className
</read_first>

<action>
In `frontend/src/components/layout/Sidebar.tsx`, find the `linkContent` variable's `<Link>` className. Currently the active condition applies:

```
'bg-[var(--to-warning)]/10 text-[var(--to-warning)] border border-[var(--to-warning)]/20'
```

Replace this with:

```
'bg-[var(--to-warning)]/10 text-[var(--to-warning)] border-l-[3px] border-l-[var(--to-warning)]/70 border-t-0 border-r-0 border-b-0 pl-[7px]'
```

Explanation:
- `border-l-[3px] border-l-[var(--to-warning)]/70` — 3px amber left accent bar at 70% opacity
- `border-t-0 border-r-0 border-b-0` — remove borders on other 3 sides
- `pl-[7px]` — compensate for 3px border so icon visual position stays aligned (original px-2.5 = 10px, minus 3px border = 7px padding)

The `pr-2.5` stays via the base `px-2.5` (which we now split: pl changes, pr unchanged via explicit `pr-2.5`). So the full active className becomes:

```
'bg-[var(--to-warning)]/10 text-[var(--to-warning)] border-l-[3px] border-l-[var(--to-warning)]/70 border-t-0 border-r-0 border-b-0 pl-[7px] pr-2.5'
```

Note: The base `className` already has `px-2.5 py-1.5` — when the active class is applied, the `pl-[7px]` overrides the left padding from `px-2.5`. Tailwind applies the more specific class last, so explicit `pl-[7px]` wins.

Keep the `{isActive && <span className='nav-active-glow' />}` span — it provides the existing CSS glow pseudo-element (defined in globals.css).
</action>
