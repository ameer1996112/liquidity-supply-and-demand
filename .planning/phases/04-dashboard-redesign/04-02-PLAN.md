# Plan 04-02: Dashboard Page — Bento Grid, Signal Animations, Mobile Stack

## Overview

Upgrades the main dashboard page and SignalTable component. Implements a bento-style hero KPI grid with `Today PnL` spanning 2 columns, adds `ConnectionPill` to the header, applies glass-panel treatment to the `WaitingBanner`, enhances signal rows with left side-colored borders and slide-in animations, and restructures the mobile layout with a live log toggle.

## Must-Haves

- KPI grid uses `xl:grid-cols-7` with `Today PnL` as `StatCard hero={true} className="col-span-1 xl:col-span-2"`
- `ConnectionPill` rendered in header right-side (imported and used in `page.tsx`)
- `WaitingBanner` has `glass-panel` class and `border-[var(--to-warning)]/30` applied
- `SignalTable` rows have left 3px border colored by signal side (green for LONG/BUY, red for SHORT/SELL)
- `SignalTable` rows have `animate-slide-in-right` class applied
- Live log hidden on mobile with toggle button visible at `xl:hidden`
