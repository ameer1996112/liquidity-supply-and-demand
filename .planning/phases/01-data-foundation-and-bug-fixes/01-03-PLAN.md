# Plan 01-03: PropFirmDetector and API

## Goal
Implement the PropFirmDetector service to lookup rules via server prefix, and expose the `/api/v1/prop-firm` endpoints for frontend consumption.

## Must Haves
- `PropFirmDetector` class
- `GET /api/v1/prop-firm/challenge-status/{account_id}`
- `PATCH /api/v1/prop-firm/challenge-config/{account_id}`
- Unknown server returning HTTP 200 with `firm_detected: false`
- Covers requirement IDs: DATA-04, API-01, API-02, API-03
