## Task 2: Rewrite src/rubric_engine.py

Replace the entire file with the new implementation. The new rubric_engine.py must:

### 2a. RubricResult dataclass
```python
@dataclass
class RubricResult:
    composite_score: float                       # 0-100
    dimension_scores: Dict[str, float]           # per-dimension contributions
    hard_veto: bool = False                      # True if any hard veto fired
    vetoed_by: Optional[str] = None             # veto name or None
    ev_score: Optional[float] = None            # (composite/100) * rr * (1 - dd_pct)
    proceed: bool = True                         # False = skip council entirely
    gate_status: str = "blocked"                 # "blocked" | "shadow" | "execute" | "disabled"
    # Legacy shims (keep score_signal compatible)
    veto_reason: Optional[str] = None           # alias for vetoed_by
    fires_council: bool = False                  # composite >= council_gate
    can_block: bool = False                      # composite >= exec_gate
```

### 2b. Four dimensions

**Liquidity Context (max 35 pts)**:
- `departure_strength` (0-100): scaled by 0.25 → 0-25 pts
- `kill_zone` (0, 1, 2): 0→0 pts, 1→5 pts, 2→10 pts
- Total: departure * 0.25 + kill_zone_lookup

**Zone Quality (max 25 pts)**:
- `return_strength` inverted: (100 - val) * 0.15 → 0-15 pts (slow return=good, fast=weak)
- `candles_to_return`/`bars_since_sweep` lookup: ≤2→10, ≤5→6, ≤10→3, >10→0 pts (raw scaled so max=10 = 10 pts)
- Total: clamped to 25 pts max

**Structural Alignment (max 25 pts)**:
- `premium_discount` + `side`: BUY in discount (pd >= 0.5) → 25; SELL in premium (pd <= 0.5) → 25; misaligned → 0
- Missing pd → 0

**Account & Environment (max 15 pts)**:
- From `account_state["daily_drawdown_pct"]` (fallback: payload["daily_drawdown_pct"])
- Linear: 0% DD → 15 pts, 80% DD → 0 pts; formula: max(0, 15 * (1 - dd_pct / 0.8))
- Cap at dd_pct=0.8 (if >= 0.8, this is a hard veto anyway)

### 2c. Hard vetoes (checked BEFORE dimension scoring)
1. `sweep_candle_close == True` → composite=0, proceed=False, vetoed_by="sweep_candle_close"
2. `session == 0` (Sydney) → composite=0, proceed=False, vetoed_by="sydney_session"
3. `account_state["daily_drawdown_pct"] > 0.80` → composite=0, proceed=False, vetoed_by="drawdown_exceeded"
4. `payload.get("news_block") is True OR payload.get("time_to_news_minutes", 999) < 30` → composite=0, proceed=False, vetoed_by="news_proximity"

### 2e. gate_status logic (applied after scoring)
```python

    gate_status = "blocked"
    proceed = False

    gate_status = "shadow"
    proceed = True  # council fires but in shadow mode
```
