# STACK

## Backend
- **Language**: Python 3.10+
- **Framework**: FastAPI (>=0.109.0) with Uvicorn
- **Rate Limiting**: slowapi (wraps limits)
- **Task Scheduling**: apscheduler

## Machine Learning & AI
- **Core ML**: scikit-learn, LightGBM (ultra-memory-efficient, replaces RandomForest), NumPy, Pandas
- **Performance**: Numba (JIT compilation for backtesting)
- **Backtesting**: backtesting.py
- **LLM/AI**: LangChain, OpenAI, Anthropic
- **Multi-Agent**: rank-bm25 (Trading Council/TradingAgents architecture)

## Frontend
- **Framework**: Next.js 16.1.6 (React 19.2.3)
- **Styling**: Tailwind CSS v4
- **Components**: Radix UI primitives, Lucide React
- **Data Fetching**: React Query (@tanstack/react-query)
- **Tables & Charts**: React Table, Recharts, Lightweight Charts
- **Dates**: date-fns

## Infrastructure
- **Database**: Supabase
- **Caching/Queue**: Redis
