# gstack

Use the `/browse` skill from gstack for all web browsing. Never use default browser tools.

## Available gstack skills

- `/office-hours` — CEO-level strategic consultation
- `/plan-ceo-review` — CEO review for any feature plan
- `/plan-eng-review` — Engineering lead review for technical plans
- `/plan-design-review` — Design lead review for UI/UX plans
- `/design-consultation` — Design consultation with a senior designer
- `/review` — Code review on any branch with changes
- `/ship` — Ship a feature end-to-end
- `/land-and-deploy` — Land and deploy a feature
- `/canary` — Canary deploy a feature
- `/benchmark` — Benchmark performance
- `/browse` — Web browsing (use this for ALL web browsing)
- `/qa` — QA your staging URL
- `/qa-only` — QA only (no code changes)
- `/design-review` — Design review on any UI
- `/setup-browser-cookies` — Set up browser cookies for auth
- `/setup-deploy` — Set up deployment pipeline
- `/retro` — Sprint retrospective
- `/investigate` — Deep investigation of a problem
- `/document-release` — Document a release
- `/codex` — Codex-style agent
- `/cso` — CSO (Chief Security Officer) review
- `/autoplan` — Auto planning
- `/careful` — Careful mode (extra caution)
- `/freeze` — Freeze the codebase
- `/guard` — Guard mode
- `/unfreeze` — Unfreeze the codebase
- `/gstack-upgrade` — Upgrade gStack to latest

> If gstack skills aren't working, run:
> `cd .antigravity/skills/gstack && ./gstack-source/browse/setup`
> to rebuild the binary and register skills.
