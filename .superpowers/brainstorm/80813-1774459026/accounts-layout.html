How should we integrate the Dashboard view for individual accounts?

You already have a dedicated page for each account (with Overview, Positions, History tabs). Where should the new "Dashboard-like" view live?

A

Replace the "Overview" Tab

Clicking an account takes you to the existing account page, but the "Overview" tab is completely upgraded to look exactly like the main Dashboard (KPIs, Active Trades, etc) scoped to that account.

B

Expandable List / Modal

Instead of navigating to a new page, clicking an account on the main Accounts list simply expands a large panel right there (or opens a modal overlay), revealing the dashboard for that account without leaving the page.
