How should account filtering work on the Dashboard?

You want to see global data, but also filter by specific account. How should we display this selector?

A

Dropdown Selector

A master dropdown at the top of the dashboard ("Global", "Account 1", "Account 2"). Clean UI, and scales well if you eventually add many accounts.

B

Quick-Switch Tabs

Horizontal tabs above the KPIs. You can click between accounts with one tap. Great for 2-4 accounts, but gets crowded if you have more.
