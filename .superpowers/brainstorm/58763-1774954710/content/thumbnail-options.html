What goes in the thumbnail (top-right of the embed)?

Discord embeds have a small thumbnail slot in the top-right corner

A

TradingView chart screenshot

When a chart image URL is attached to the signal, show it as the thumbnail. Falls back to nothing if no image. You already have this field (image_url) in NotificationPayload.

🛑 SL: 1.08320
💰 TP: 1.08620

B

Symbol badge (currency flag or colored tile)

Always show something in the thumbnail — a colored badge with the symbol abbreviation. EUR gets an EU flag style, XAU gets a gold tile, US30 gets an index badge. No dependency on TradingView screenshots.

C

Chart when available, symbol badge as fallback

Best of both: if the signal includes a TradingView chart URL, show the chart. If not, fall back to the symbol badge automatically. Most flexible — works for both screenshot-enabled and screenshot-less signals.
